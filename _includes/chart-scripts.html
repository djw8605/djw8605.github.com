{%- comment -%} Loads Chart.js and its annotation plugin, then draws every chart.html figure on the page. _layouts/default.html includes this only when the page sets `charts: true`, so no other page loads chart JS. Both builds are pinned with SRI hashes. To upgrade, change a version and its integrity value together, then check a chart in both themes and at phone width. Colours come from the --chart-* custom properties in assets/css/main.scss, so the HTML legend and the canvas share one palette per theme. A class change on (the theme toggle or the system preference) redraws every chart. The renderer is a module script: module scripts run after the deferred builds above, in document order, and jekyll-minifier leaves them alone. {%- endcomment -%}
